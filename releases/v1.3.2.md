# AltServer Setup v1.3.2 — experimental prerelease

Ready-to-install macOS27 / Apple silicon DMG with patched iPhone AltStore2.3.1 / 6402 embedded. No compilation or separate IPA selection.

## Install / 설치

Drag AltServer into Applications, quit the older running copy, open the new one, connect/unlock iPhone by USB and choose **Install AltStore → your iPhone**. Enter your own Apple Account/2FA. Use your existing account when replacing AltStore; do not uninstall first. Verify iPhone version2.3.1 / build6402. Ad-hoc signed, not notarized; use the normal Privacy & Security → Open Anyway action if blocked.

## Changes and verification

- Mac1.8-pr1834-public-v1.3.2 / 183402 selects the bundled patched IPA through its ordinary installation menu. Upstream fallback is retained for source builds without the resource.
- iPhone client shares Windows GSA identity/cryptography with the tested Mac lineage, refreshes anisette per authentication instance, and adds fixed stage/status diagnostics only. No automatic503 retry or iOS hsc434 resync is added.
- The public IPA preserves tested6402 executable code; recipient placeholders are reset and its outer ad-hoc signature regenerated. AltServer personalizes/signs it for the recipient.
- Complete Mac/iPhone corresponding source, pinned dependency sources, licenses and rebuild scripts are supplied. After temporary-folder cleanup, sources were recovered from the publishedv1.3.1 source plus exact prior reviewed source records and rebuilt. Restricted Apple crypto implementation/static libraries/copied headers are excluded; an opaque system SRP adapter plus CryptoKit/CommonCrypto is used.
- Previous real-account evidence: Macv1.3.1 USB installation succeeded on macOS27.0.1 / iOS27.2. Companion client code refreshed over USB+cellular, and twice consecutively over USB+Wi-Fi after per-network DNS1.1.1.1/1.0.0.1, with newly issued device profiles confirmed. These are limited observations; finalv1.3.2 packaging did not receive a new real-account installation test.

## Remaining failures

[HTTP503 investigation](../docs/refresh-http-503.md): DNS helped this tested setup, but another ISP report required a different network and did not improve with DNS. Record original settings and revert ineffective changes. Certificate changes can cause a large app to be reinstalled, explaining slower first refreshes.

[Issue14 invalid anisette](../docs/invalid-anisette.md): the reporterv1.3.1 statement is known, iPhone build/numeric error/stage remain unknown. Clock advice is generic; hsc434 is only a possible source path, not an observed reporter result. This release is not a confirmed #14 fix.

[Reddit/GitHub community investigation](../docs/community-findings.md): includes solved and unresolved reports, dates, platform differences and evidence limits.

Mac requires macOS27 arm64. iPhone deployment minimum iOS17.4; actual device evidence limited to iOS27.2. Other accounts/devices/OS combinations and USB-free refresh unverified. External ani.jkcoxson.com is an availability/privacy dependency and observes connection metadata; passwords/2FA go only to Apple. No runtime identity, private signing keys or recipient pairing records are supplied. Nested upstream AltBackup.ipa has its public upstream provisioning profile. No automatic DNS/security changes.
