## Changes

Based on AltStore Classic [PR #1834](https://github.com/altstoreio/AltStore/pull/1834), head `ddb4415`, and [AltSign PR #61](https://github.com/rileytestut/AltSign/pull/61), commit `832d9ce`. Removes the bundled Apple static corecrypto library and restricted headers. SRP uses macOS system private functionality through an opaque interface, with CryptoKit/CommonCrypto for cryptography. This documents the contents of this build; it does not make a broader legal determination.

Sign-in obtains Windows ADI anisette data from `ani.jkcoxson.com`, with matching client identity and User-Agent. This external service is a runtime dependency. Its availability and privacy practices affect use; it can observe connection metadata. The Apple Account password and 2FA code are sent only to Apple.

## Verification and limits

- Protocol tests: 5/5 passed, including PBKDF2 `s2k` and `s2k_fo` vectors, invalid CBC padding, GCM AAD tampering, and malformed SRP.
- Independent handshake check accepted valid M2, rejected bad M2, and matched the session key exactly.
- App build, launch, and Windows-identity smoke checks passed.
- On 2026-10-16, real-account sign-in and USB installation of AltStore 2.3 (build 64) succeeded on macOS 27.0.1 / Apple silicon with iOS 27.2. Two installation attempts reached 100% and completion; the installed profile validated. No HTTP 503 was observed in these attempts. iPhone Refresh All succeeded for two of three apps, but YouTube failed with ServerError 2002 (lost connection). A subsequent YouTube-only retry returned AppleDeveloperError 3000 / HTTP 503. Full app refresh is not verified; these failures remain under investigation.
- Optional remote-pairing setup failed after a delay of about two minutes, then USB installation continued successfully. An apparent pause after clicking Install can therefore precede a successful installation; this does not establish that remote pairing works.

This is an experimental prerelease, not a guarantee of compatibility or service availability. The app is not notarized. See [security and privacy](../SECURITY.md), [third-party notices](../THIRD_PARTY_NOTICES.md), [upstream provenance](../UPSTREAM_SOURCE.md), and [build notes](../BUILDING.md).

### 변경 사항 및 검증

AltStore Classic [PR #1834](https://github.com/altstoreio/AltStore/pull/1834)와 [AltSign PR #61](https://github.com/rileytestut/AltSign/pull/61) 기반입니다. Apple 정적 corecrypto 라이브러리와 제한된 헤더를 제거하고, 불투명 인터페이스를 통한 macOS 시스템 private SRP와 CryptoKit/CommonCrypto를 사용합니다. 이는 빌드 구성 설명이며 더 넓은 법적 판단은 아닙니다.

Windows ADI anisette 데이터에 외부 서비스 `ani.jkcoxson.com`을 사용합니다. 서비스 가용성 및 개인정보 처리에 영향을 받으며 연결 메타데이터가 노출될 수 있습니다. Apple 계정 암호와 2단계 인증 코드는 Apple에만 전송됩니다.

프로토콜 테스트 5/5 통과(PBKDF2 `s2k`/`s2k_fo` 벡터, 잘못된 CBC padding, GCM AAD 변조, 잘못된 SRP 포함). 별도 핸드셰이크 테스트는 올바른 M2를 수락하고 잘못된 M2를 거부했으며 세션 키가 정확히 일치했습니다. 앱 빌드·실행·Windows identity smoke test도 통과했습니다. 2026-10-16 macOS 27.0.1/Apple silicon과 iOS 27.2에서 실제 계정 로그인 후 AltStore 2.3(build 64)의 USB 설치가 성공했습니다. 두 번 모두 설치 100% 및 완료 로그와 설치 프로파일 유효 상태를 확인했으며 해당 시도에서 HTTP503은 관찰되지 않았습니다. iPhone Refresh All은 3개 중 2개 성공했고 YouTube는 ServerError2002(연결 끊김)로 실패했습니다. YouTube 단독 재시도에서는 AppleDeveloperError3000/HTTP503이 발생했습니다. 전체 앱 갱신 성공은 확인하지 못했으며 원인을 조사 중입니다.

원격 기능용 페어링 준비가 약 2분 지연 후 실패했지만, 선택적인 페어링 파일 삽입을 건너뛰고 USB 설치는 정상 완료됐습니다. Install 직후 반응이 없어 보이는 현상과 설치 실패를 구분해야 하며, 이 결과가 원격 페어링 성공을 의미하지는 않습니다.

실험용 사전 릴리스로 호환성이나 서비스 가용성을 보장하지 않습니다. DMG 및 소스 archive의 SHA-256은 위 표와 `SHA256SUMS.txt`에서 확인하세요. 독립적인 소스 및 제한 자료 검토와 추출된 소스의 clean build를 통과했습니다.

## 2026-10-16 follow-up: iPhone network comparison

Further tests used a **local, unpublished AltStore 2.3.1/build 6402 iPhone client**, not the official iPhone client bundled by a normal installation. That client still encountered intermittent HTTP 503 at the first GSA `init` request on Wi-Fi. Cellular refresh with USB retained succeeded; after changing only the iPhone’s per-network Wi-Fi DNS to `1.1.1.1` / `1.0.0.1`, two consecutive Wi-Fi refreshes succeeded. Mac logs and the device’s newly issued provisioning profiles confirmed renewal. This identifies a working configuration for one setup; it does not establish a universal DNS cause or that the public DMG plus the official iPhone client fixes refresh. The experimental iPhone IPA is not included in this release. See the [troubleshooting record](https://github.com/kimziro/altserver-macos27-anisette-fix/blob/main/docs/refresh-http-503.md).

미공개 iPhone 시험판 2.3.1/build 6402에서 Wi-Fi의 첫 인증 요청 503이 재발했지만, USB 유지/LTE 갱신은 성공했습니다. 이후 iPhone의 해당 Wi-Fi DNS만 `1.1.1.1` / `1.0.0.1`로 변경하자 연속 두 번 성공했고, Mac 로그와 기기의 새 프로파일로 갱신을 확인했습니다. 한 환경에서 확인한 설정이며 모든 503의 DNS 원인이나 공식 iPhone 앱 조합의 성공을 입증한 것은 아닙니다. 이 릴리스에 iPhone 시험 IPA는 포함되지 않습니다.
