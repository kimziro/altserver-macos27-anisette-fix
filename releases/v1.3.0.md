# AltServer macOS 27 Anisette Fix v1.3.0 — source-only prerelease

**Status:** Source-only prerelease (2026-10-15). No DMG, app, or binary download is available.

## Candidate

The project package version is v1.3.0. The source-based app lineage is labelled `1.8-pr1834-test/1834`; it is not a patched official AltServer 1.8.1 binary.

- AltStore Classic source: [PR #1834](https://github.com/altstoreio/AltStore/pull/1834), head `ddb4415cc6aeeb3145de33a29f7064292a45d895`.
- AltSign: [PR #61](https://github.com/rileytestut/AltSign/pull/61), pinned commit `832d9cec339ea6ef6891011833dbb7227b028a29`.
- Authentication obtains Windows ADI anisette v3 from `ani.jkcoxson.com` and sends matching `client_info` and User-Agent. This changes the native sign-in path; it is not a descriptor-only substitution.

The PR author's explanation of Apple's rejection behavior is a hypothesis, not an independently confirmed Apple policy cause.

## Reported evidence and limits

In one test setup, official AltServer returned `-80045`; the earlier Pixel-descriptor-only experiment returned HTTP 503. A smoke test of the candidate received all required Windows identity fields. The maintainer reported signing in and refreshing apps. An earlier screen showed YouTube with six days remaining and two other apps with seven; the maintainer later reported all three refreshed while connected by USB. This is a user report, not independent verification. The USB result does not establish whether earlier successful refreshes used USB or Wi-Fi, and it does not establish wireless success, reboot persistence, or broad compatibility. The cause of the original error is not independently confirmed.

## Distribution blocker

The locally tested candidate statically links `libcorecrypto_static.a`. Its [License.txt](https://github.com/rileytestut/AltSign/blob/832d9cec339ea6ef6891011833dbb7227b028a29/Dependencies/corecrypto/License.txt) states Apple Internal Use only and prohibits redistribution. The v1.3.0 prerelease therefore contains source patches, pinned upstream references, and test/result documentation only. Do not include or distribute an app, DMG, static library, or binary built with that component unless the build/review team resolves this exact restriction. This notice does not authorize ignoring or overriding the license.

No binary asset is supplied. `SHA256SUMS.txt` contains only the source archive SHA-256 for download verification. The separate `verification-manifest.txt` records the tested local executable hash for provenance only; it is not an available binary download. Source references: [build notes](https://github.com/kimziro/altserver-macos27-anisette-fix/blob/main/BUILDING.md), [security notes](https://github.com/kimziro/altserver-macos27-anisette-fix/blob/main/SECURITY.md), [third-party notices](https://github.com/kimziro/altserver-macos27-anisette-fix/blob/main/THIRD_PARTY_NOTICES.md), and [upstream provenance](https://github.com/kimziro/altserver-macos27-anisette-fix/blob/main/UPSTREAM_SOURCE.md). The source archive includes patch notes at `compatibility/v1.3.0/README.md`.

## 한국어

# AltServer macOS 27 Anisette Fix v1.3.0 — 소스 전용 사전 릴리스

**상태:** 2026-10-15 소스 전용 사전 릴리스입니다. DMG, 앱 또는 바이너리 다운로드는 없습니다.

### 후보

프로젝트 패키지 버전은 v1.3.0입니다. 앱 계열 표기는 `1.8-pr1834-test/1834`이며, 공식 AltServer 1.8.1 바이너리 패치가 아닌 AltStore Classic 소스 기반입니다.

- AltStore Classic 소스: [PR #1834](https://github.com/altstoreio/AltStore/pull/1834), head `ddb4415cc6aeeb3145de33a29f7064292a45d895`.
- AltSign: [PR #61](https://github.com/rileytestut/AltSign/pull/61), 고정 commit `832d9cec339ea6ef6891011833dbb7227b028a29`.
- 로그인 과정은 `ani.jkcoxson.com`에서 Windows ADI anisette v3를 가져오고, 이에 맞는 `client_info`와 User-Agent를 사용합니다. descriptor 문자열만 바꾸는 수정이 아닙니다.

Apple이 요청을 거부하는 원인에 관한 PR 작성자의 설명은 가설이며, 독립적으로 확인된 Apple 정책 원인이 아닙니다.

### 보고된 검증과 한계

한 테스트 환경에서 공식 AltServer 로그인은 `-80045`, 이전 Pixel descriptor만 바꾼 실험은 HTTP 503을 반환했습니다. 후보 smoke test는 필수 Windows identity 필드를 받았습니다. 관리자는 로그인 및 앱 갱신 성공을 보고했고, 이후 iPhone을 USB로 연결한 상태에서 앱 세 개 모두 갱신됐다고 추가 보고했습니다. 이는 독립적으로 검증된 결과가 아닌 사용자 보고입니다. USB 결과로 앞선 성공의 연결 방식이 USB였는지 Wi-Fi였는지 알 수 없고, 무선 성공·재부팅 후 지속성·폭넓은 호환성을 입증하지 않습니다. 최초 오류의 원인도 독립적으로 확정되지 않았습니다.

### 배포 제한

로컬 테스트 후보는 `libcorecrypto_static.a`를 정적으로 링크합니다. upstream [License.txt](https://github.com/rileytestut/AltSign/blob/832d9cec339ea6ef6891011833dbb7227b028a29/Dependencies/corecrypto/License.txt)는 Apple Internal Use only 및 재배포 금지를 명시합니다. 따라서 v1.3.0 사전 릴리스에는 소스 패치, 고정된 upstream 참조, 테스트/결과 문서만 포함합니다. 빌드/검토팀이 이 제한을 해결하기 전까지 해당 구성요소로 만든 앱, DMG, 정적 라이브러리 또는 바이너리를 포함하거나 배포하지 마세요. 이 안내는 라이선스 무시나 재배포를 허가하지 않습니다.

바이너리 자산은 제공하지 않습니다. `SHA256SUMS.txt`에는 다운로드 검증용 소스 archive SHA-256만 포함합니다. 별도 `verification-manifest.txt`는 테스트한 로컬 실행 파일의 provenance용 해시만 기록하며, 다운로드 가능한 바이너리라는 뜻이 아닙니다. 문서: [빌드 안내](https://github.com/kimziro/altserver-macos27-anisette-fix/blob/main/BUILDING.md), [보안 안내](https://github.com/kimziro/altserver-macos27-anisette-fix/blob/main/SECURITY.md), [제3자 고지](https://github.com/kimziro/altserver-macos27-anisette-fix/blob/main/THIRD_PARTY_NOTICES.md), [upstream 출처](https://github.com/kimziro/altserver-macos27-anisette-fix/blob/main/UPSTREAM_SOURCE.md). 소스 archive에 `compatibility/v1.3.0/README.md` 패치 안내가 포함됩니다.
