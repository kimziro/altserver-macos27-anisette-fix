# AltServer macOS 27 Anisette Fix v1.2.0

**Release date:** 2026-10-14

[Download the DMG](https://github.com/kimziro/altserver-macos27-anisette-fix/releases/download/v1.2.0/AltServer-macOS27-Anisette-Fix-v1.2.0.dmg)

## English

### What changed

- Updates the packaged official AltServer base from 1.7.6/build 94 (used by v1.0.9) to **1.8.1/build 98**. The package release number `v1.2.0` is not the AltServer app version.
- Changes only Mac-side client information; the iPhone app and sign-in flow are unchanged.
- Does not include the older remote V3 fallback helper or an iOS app/authentication-flow patch.

### Why

This targets the macOS 27 Apple sign-in and refresh error `-80045`. It is distinct from the older `machineID` failure addressed by v1.0.8/v1.0.9's V3 fallback. The fix does not alter authentication.

### Verification and limits

On 2026-10-14, an installed v1.2.0 test build on one Apple Silicon Mac running macOS 27 completed Refresh All for three existing apps on one iPhone. All three showed seven days remaining; the refresh indicators finished without a visible error or 2FA prompt. The final distribution copy was read back, passed strict signature verification, and started successfully. Its main executable code matched the tested app for both architectures. No new three-app refresh is claimed for that distribution copy. See [build notes](../BUILDING.md) for implementation and artifact checks.

This is one test only. USB versus Wi-Fi was not established. Remote anisette, reboot, a new login or 2FA flow, Intel Macs, other devices/accounts, and universal compatibility were not tested. Do not reinstall AltStore on the iPhone solely for this Mac-side change. Leave **Prefer Remote** off for refresh through this Mac app; if separately trying wireless refresh, keep Mac and iPhone on the same Wi-Fi network.

The DMG contains an ad-hoc-signed app and is not notarized by Apple. Read the [installation and safety instructions](../README.md) and [security notes](../SECURITY.md). Verify the DMG against the release's `SHA256SUMS.txt`.

## 한국어

### 변경 내용

- v1.0.9의 AltServer 1.7.6/build 94 기반 패키지에서 공식 AltServer **1.8.1/build 98** 기반으로 변경했습니다. `v1.2.0`은 프로젝트 release 번호이며 AltServer 앱 버전과 다릅니다.
- Mac 쪽 client 정보만 수정합니다. iPhone 앱과 로그인 흐름은 변경하지 않습니다.
- 이전 원격 V3 fallback helper나 iOS 앱/인증 흐름 패치는 포함하지 않습니다.

### 수정 대상

이 변경은 macOS 27의 Apple 로그인·갱신 오류(`-80045`)를 대상으로 합니다. v1.0.8/v1.0.9의 V3 fallback이 다룬 과거 `machineID` 오류와는 구분됩니다. 인증 흐름은 변경하지 않습니다.

### 검증 및 한계

2026-10-14, macOS 27을 실행하는 Apple Silicon Mac 한 대에서 설치된 v1.2.0 테스트 빌드로 iPhone 한 대의 기존 앱 세 개에 Refresh All을 완료했습니다. 세 앱 모두 남은 기간이 7일로 표시됐고, 새로 고침 표시가 끝났으며 화면에 오류나 2FA 요청은 보이지 않았습니다. 최종 배포본은 다시 읽어 strict 서명 검증을 통과하고 정상 실행됐습니다. 두 아키텍처의 실행 코드가 테스트 앱과 일치하는 것을 확인했습니다. 최종 배포본에서 세 앱 Refresh All을 다시 했다고 주장하지 않습니다. 구현과 artifact 확인은 [빌드 안내](../BUILDING.md)를 참고하세요.

검증은 환경 한 번에 한정됩니다. USB/Wi-Fi 중 어떤 연결이었는지 확인하지 않았습니다. 원격 anisette, 재부팅, 새 로그인 또는 2FA 흐름, Intel Mac, 다른 기기/계정, 전체 호환성은 테스트하지 않았습니다. 이 Mac 수정만을 위해 iPhone에 AltStore를 다시 설치할 필요는 없습니다. 이 Mac 앱으로 새로 고침할 때는 **Prefer Remote**를 끄세요. 무선 새로 고침을 별도로 시험한다면 Mac과 iPhone을 같은 Wi-Fi에 연결하세요.

DMG의 앱은 ad-hoc 서명만 되었고 Apple 공증을 받지 않았습니다. [설치 및 안전 안내](../README.ko.md)와 [보안 안내](../SECURITY.md)를 읽고, release의 `SHA256SUMS.txt`로 DMG를 확인하세요.
